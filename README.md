# PIXEL – Interactive Image Processing & Analysis Studio

## 📌 Project Description

PIXEL is a web-based Image Processing and Analysis application developed using Python and Flask.

The application provides an interactive platform where users can upload or capture an image and perform different image processing and computer vision operations.

The project uses OpenCV and NumPy for image processing and analysis, while Flask is used for backend processing and communication with the web interface.

---

## 🎯 Objectives

- To provide a simple web-based image processing platform.
- To perform different image processing operations using Python.
- To provide an easy-to-use interface for students and beginners.
- To analyze image properties such as resolution, brightness, contrast and channels.
- To visualize RGB histogram information.
- To compare original and processed images.
